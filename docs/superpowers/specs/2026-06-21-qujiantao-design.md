# 区间套分析功能 - 设计规范

## 1. 项目概述

**功能名称**：区间套（QujianTao / QJT）多级别嵌套分析

**核心能力**：基于缠论理论，在 日线→30分钟→5分钟→1分钟 4个级别上独立识别分型、笔、线段、中枢，然后通过价格区间叠加、方向一致性、时间区间匹配三个条件复合判定，最终输出高置信度的精确买卖点信号。

**目标用户**：熟练掌握缠论的A股投资者，用于精确定位买卖点

---

## 2. 级别链条（方案A）

```
Level 1: 日线 (daily)   — 大级别趋势方向判定
   └─ Level 2: 30分钟 (30m) — 次级别结构确认
         └─ Level 3: 5分钟 (5m) — 次级别的次级别定位
               └─ Level 4: 1分钟 (1m) — 精确买点/卖点定位
```

每一级别独立运行完整的缠论诊断流程（分型→笔→线段→中枢→趋势→背驰）。

---

## 3. 判定方案（方案C：复合判定）

区间套信号必须**同时**满足以下三个条件：

### 条件1：价格区间叠加

各级别中枢的价格区间必须有交集。

```
  日线中枢区间:   [10.50, 11.20]
  30分钟中枢区间: [10.80, 11.00]
  5分钟中枢区间:  [10.90, 10.98]
  1分钟中枢区间:  [10.92, 10.96]
  ──────────────────────────────
  价格交集:       [10.92, 10.96] ✓ 存在
```

算法：取所有级别的价格区间上限的最小值和下限的最大值，若 min_upper > max_lower，则存在交集。

### 条件2：方向一致性

所有级别必须指向同一方向（全 buy 或 全 sell）。

- **buy 信号**：各级别背驰信号均为向上背驰的反转，或各级别趋势均为"下跌趋势"且出现底分型
- **sell 信号**：各级别背驰信号均为向下背驰的反转，或各级别趋势均为"上涨趋势"且出现顶分型
- 若有任一方向与其他级别矛盾 → 不构成区间套信号

### 条件3：时间区间匹配

小级别的关键时间区间必须落在大级别关键时间区间之内。

```
  日线的关键时段:    第 180-220 根K线
  30分钟的关键时段:  第 400-450 根K线  → 映射到日线 200-215 根 ✓
  5分钟的关键时段:   第 2000-2100 根K线 → 映射到30分钟 410-435 根 ✓
  1分钟的关键时段:   ...              → 逐级向内收敛 ✓
```

**级别换算系数**：
- 1 根日K ≈ 8 根30分钟K ≈ 48 根5分钟K ≈ 240 根1分钟K

## 4. 数据结构

### 4.1 单级别诊断数据

```python
class LevelData(BaseModel):
    level: str                      # "1m" / "5m" / "30m" / "daily"
    level_name_cn: str              # "1分钟" / "5分钟" / "30分钟" / "日线"
    klines: List[KLine]             # 该级别K线数据
    diagnosis: DiagnosisResult      # 该级别完整诊断结果
    key_price_range: List[float]    # 关键价格区间 [low, high]
    key_time_range: List[int]       # 关键时间区间 [start_idx, end_idx]
    direction: Optional[str]        # "buy" / "sell" / None
    has_zhongshu: bool              # 是否存在中枢
    has_beichi: bool                # 是否存在背驰
```

### 4.2 区间套信号

```python
class QJTSignal(BaseModel):
    levels_involved: List[str]      # 涉及的级别，如 ["daily", "30m", "5m", "1m"]
    direction: str                  # "buy" / "sell"
    price_intersection: List[float] # 价格交集区间 [low, high]
    confidence: float               # 置信度 0.0 - 1.0
    price_score: float              # 价格重叠得分 0-1
    direction_score: float          # 方向一致得分 0-1
    time_score: float               # 时间匹配得分 0-1
    description: str                # 文字描述，用于前端展示
    precise_price: float            # 推荐操作价位（交集中心点）
```

### 4.3 多级别诊断总结果

```python
class MultiLevelResult(BaseModel):
    code: str
    name: str
    levels: Dict[str, LevelData]   # key: "1m", "5m", "30m", "daily"
    qjt_signals: List[QJTSignal]
    overall_assessment: str        # 总体评估文字描述
    highest_confidence_signal: Optional[QJTSignal]  # 最高置信度信号
```

## 5. 缠论计算引擎（复用核心模块）

### 5.1 核心模块清单

| 模块 | 文件 | 功能 |
|------|------|------|
| 数据模型 | `chanlun/models.py` | KLine, FenXing, Bi, Segment, Zhongshu, DiagnosisResult, LevelData, QJTSignal, MultiLevelResult |
| 分型检测 | `chanlun/detector.py` | 识别顶/底分型 |
| 笔分析 | `chanlun/bi.py` | 构建笔（至少5根K线） |
| 线段分析 | `chanlun/segment.py` | 每3笔构成一条线段 |
| 中枢检测 | `chanlun/zhongshu.py` | 检测三段方向交替形成的中枢 |
| 趋势分析 | `chanlun/trend.py` | 判断上涨/下跌/盘整 |
| 背驰检测 | `chanlun/beichi.py` | 检测同向段力度减弱 |
| 单级别诊断 | `chanlun/diagnosis.py` | 整合以上6模块的单级别完整诊断 |

### 5.2 诊断流水线（单级别）

```
K线输入
  ↓
FenXingDetector → 分型列表
  ↓
BiAnalyzer → 笔列表（分型构建）
  ↓
SegmentAnalyzer → 线段列表（笔构建）
  ↓
ZhongshuDetector → 中枢列表（线段构建）
  ↓
TrendAnalyzer → 趋势标签
  ↓
BeichiDetector → 背驰信号
  ↓
LevelData → 加上关键区间和方向标签
```

## 6. 区间套判定引擎（QJT Engine）

### 6.1 输入输出

- **输入**：`Dict[str, LevelData]`（4个级别的诊断结果）
- **输出**：`List[QJTSignal]`（按置信度排序的信号列表）

### 6.2 三阶段判定算法

```python
# 阶段1：价格区间叠加得分
price_overlap_ratio = intersection_length / smallest_level_range

# 阶段2：方向一致性得分
direction_consistency = same_direction_count / total_levels

# 阶段3：时间区间匹配得分
time_containment = containment_ratio（小级别是否在大级别内部）

# 综合置信度
confidence = (price_overlap_ratio * 0.35)
           + (direction_consistency * 0.35)
           + (time_containment * 0.30)

# 仅当三条件都满足（confidence > 0.5）时输出信号
```

### 6.3 信号级别分类

| 涉及级别数 | 信号等级 | 置信度范围 |
|-----------|---------|-----------|
| 4级叠加 | 极高置信 | 0.8 - 1.0 |
| 3级叠加 | 高置信 | 0.6 - 0.8 |
| 2级叠加 | 中等置信 | 0.5 - 0.6 |
| < 2级 | 无信号 | - |

### 8.2 交互特性

- **悬停联动**：鼠标悬停某一级别K线时，其他级别图上高亮显示对应的时间/价格位置

- **缩放同步**：所有图表缩放联动（时间轴按比例换算）

## 9. 多级别数据获取

### 9.1 akshare 级别映射

| 级别 | akshare `period` 参数 | 推荐K线数 |
|------|----------------------|-----------|
| 日线 | `"daily"` | 250根（约1年） |
| 30分钟 | `"30"` | 500根（约3周） |
| 5分钟 | `"5"` | 1000根（约1周） |
| 1分钟 | `"1"` | 2000根（约5天） |

### 9.2 数据获取流程

```python
# 1. 并行获取4级别数据（提高响应速度）
# 2. 若某级别数据获取失败，降级处理（跳过该级别，仅用可用级别分析）
# 3. 对每级数据运行 ChanLunDiagnosis
# 4. 汇总到 MultiLevelResult
```

## 11. 约束与限制

- **数据源**：依赖 akshare（东方财富/新浪财经接口），接口稳定性取决于外部服务
- **小级别数据**：1分钟/5分钟数据通常只能获取最近数天至数周，历史数据有限
- **算法简化**：中枢识别为简化版（三段方向交替），非严格缠论定义
- **仅供参考**：输出信号为技术分析辅助工具，不构成投资建议
